# YouTube Dashboard

This is the Next.js dashboard for the YouTube Tracker app. It calls backend APIs (see `youtube-dashboard/src/lib/api.ts`) and renders analytics, outliers, and insights.

## Quick start (dashboard)

1. Install dependencies and start the dashboard dev server from the `youtube-dashboard` folder:

   ```bash
   npm install
   npm run dev
   ```

2. Open the dashboard in your browser at <http://localhost:5000>

Tip: the project includes a root-level `dev:all` script that starts both backend and dashboard together (uses `concurrently`).

## Learn more

Read the main repo README for backend setup and API details. For Next.js docs, see <https://nextjs.org/docs>.
